# Campus Life App — MVP

A student-focused website based on the wireframe, with four connected pages: Home, Events, Dining, and Studying.

## MVP features
- Internal navigation across four HTML pages.
- Responsive layout using Bootstrap and custom CSS.
- Home page sample announcement fetched from JSONPlaceholder.
- Event search and category filtering.
- Dining search and meal-type filtering.
- Study location search and quiet/group filtering.
- Placeholder content clearly marked as sample data.
- Semantic headings, form labels, and navigation labels.

## Technologies
HTML5, CSS3, JavaScript, Bootstrap 5.3.8, JSONPlaceholder demo API.

## Run locally
Open the folder in VS Code and use Live Server, or open `index.html` in a browser. No build tools are required.

## GitHub Pages deployment
Push the project to GitHub. In repository Settings > Pages, choose Deploy from a branch, select `main` and `/ (root)`, and save. Copy the published URL shown on that page.

## Limitations and future improvements
Event, dining, and study information are placeholders rather than verified campus information. JSONPlaceholder is a demo API, not a campus data source. For the final project, connect at least two relevant APIs, add accurate campus details, improve detail views, and test accessibility and responsive behavior.
